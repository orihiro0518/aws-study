ポイントを詳しく理解する

ここは試験で選択肢を見分けるために、用語だけでなく「何のために使うか」まで押さえます。

VPCはAWS内の自分専用ネットワーク

IPアドレス範囲を決め、その中にEC2やデータベースなどを配置する論理的に分離されたネットワークです。

サブネットでネットワークを分割

VPCを小さなネットワークに分けます。一般に外部公開するWeb層と直接公開しないDB層などを分離して設計します。

Internet GatewayはVPCとインターネットの出入口

インターネット接続が必要な構成で利用します。ただし付けただけで全リソースが自動公開されるわけではなく、ルート等の設定も関係します。

NAT GatewayはPrivate側からの外向き通信で登場

Private subnetのインスタンスが更新ファイル取得などでインターネットへ出たい一方、外部から直接接続されたくない場合に使われます。

Security Groupはリソース単位の通信制御

EC2などに適用するステートフルな仮想ファイアウォールです。『誰から何番ポートを許可するか』を考えます。

高可用性では複数AZを意識

1つのAZだけに全システムを置くより、複数AZへ分散することで障害への耐性を高められます。

試験ではどう考える？

問題文ではサービス名そのものではなく、要件や課題が提示されることがあります。まず「計算・保存・ネットワーク・セキュリティ・コスト」など目的を特定し、その目的に合うサービスへ絞り込みます。似たサービスが並んだ場合は、運用負荷、データ形式、接続方法、セキュリティ上の目的などの違いを確認します。

もう一段深く理解する

Amazon VPCはAWS上に論理的に分離された仮想ネットワークを作るサービスです。サブネット、ルートテーブル、Internet Gateway、NAT Gateway、セキュリティグループなどを組み合わせます。

覚え方： VPC＝『AWS内に作る自分専用のネットワーク区画』。

似たサービスとの比較

Public subnetインターネット向け経路を持たせる構成
Private subnet直接インターネット公開しない構成
Security Groupインスタンス等に適用するステートフルな仮想FW

試験での見分け方

  • Webサーバー公開→Public subnetを検討
  • DBを直接公開しない→Private subnet
  • Private subnetから外向き通信→NAT Gateway

※ 試験ではサービス名だけでなく、要件・運用負荷・可用性・コストなどの条件から判断する問題が出ます。

Q1. AWS内の仮想ネットワークを作るサービスは？
答え：Amazon VPC
Q2. Private subnetからインターネットへ外向き通信する代表手段は？
答え：NAT Gateway
Q3. EC2などへの通信を制御するステートフルな仕組みは？
答え：Security Group
