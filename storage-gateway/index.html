AWS Storage Gatewayとは？

公開日：2026-08-31 ｜ 更新日：2026-09-03

オンプレミスとAWSストレージをつなぐハイブリッド構成を理解する。

まず図でつかむ

On-premises既存環境
Storage Gateway橋渡し
AWS StorageS3等
Hybrid段階的にクラウド活用

覚え方： 名前を丸暗記するより「何をしたい時に使うか」を1行で説明できるようにすると、選択問題で判断しやすくなります。

ポイントを詳しく理解する

ここは試験で選択肢を見分けるために、用語だけでなく「何のために使うか」まで押さえます。

オンプレとAWSストレージの橋渡し

既存オンプレミス環境からAWSのクラウドストレージを利用しやすくするハイブリッドストレージサービスです。

既存アプリを活かしたい場合に有効

オンプレ側の仕組みをすぐ全面改修せず、クラウドストレージと統合したいケースで候補になります。

DataSyncとは目的が違う

Storage Gatewayは継続的なハイブリッドストレージ利用、DataSyncはデータを効率的に転送・同期する用途、と整理します。

試験ではどう考える？

問題文ではサービス名そのものではなく、要件や課題が提示されることがあります。まず「計算・保存・ネットワーク・セキュリティ・コスト」など目的を特定し、その目的に合うサービスへ絞り込みます。似たサービスが並んだ場合は、運用負荷、データ形式、接続方法、セキュリティ上の目的などの違いを確認します。

もう一段深く理解する

AWS Storage Gatewayはオンプレミス環境とAWSストレージをつなぐハイブリッドクラウドストレージサービスです。既存環境からクラウドストレージを利用しやすくします。

覚え方： Storage Gateway＝『オンプレとAWSストレージの玄関口』。

似たサービスとの比較

Storage GatewayオンプレとAWSストレージを橋渡し
S3AWSのオブジェクトストレージ
DataSyncオンプレ/AWS間などのデータ転送を自動化

試験での見分け方

  • 既存オンプレアプリからクラウドストレージを利用→Storage Gateway
  • 大量ファイルをオンライン転送→DataSync
  • 純粋なオブジェクト保存→S3

※ 試験ではサービス名だけでなく、要件・運用負荷・可用性・コストなどの条件から判断する問題が出ます。
